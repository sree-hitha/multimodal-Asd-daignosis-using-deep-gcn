This project presents a Multimodal Deep Graph Convolutional Network (Deep GCN) framework for the early diagnosis of Autism Spectrum Disorder (ASD). The proposed approach integrates multiple data modalities, such as neuroimaging, behavioral assessments, and clinical information, to improve diagnostic accuracy and capture complex relationships between different features.

By leveraging Graph Convolutional Networks (GCNs), the model learns meaningful representations from graph-structured data, enabling better classification of ASD compared to traditional machine learning methods.

Features
Multimodal data integration
Deep Graph Convolutional Network architecture
Automated feature learning
ASD classification
High diagnostic accuracy
Scalable and extensible framework
End-to-end deep learning pipeline
